# design-comp

Forma — Minimal AI Design Copilot (UI Prototype)

A lightweight, minimal light-theme UI prototype for:
1. **Layout Brainstormer**: Preview wireframes and responsive layouts (Desktop & Mobile) across various product archetypes (SaaS Analytics, E-commerce PDP, Mobile Banking, User Onboarding).
2. **UI Copy Generator**: Generate contextual microcopy for Buttons/CTAs, Hero Headlines, Empty States, and Error alerts with tone adjustments (Minimal & Direct, Playful & Friendly, Enterprise).
3. **Usability Feedback Synthesizer**: Summarize user testing transcripts, identify core friction points, track sentiment polarity, and generate prioritized design recommendations.

## Quick Start
Open `index.html` directly in any web browser, or run:
```bash
npm install
npm run dev
```
